 E-Commerce Sales Analytics (SQL + Python)

*Project Overview
This project focuses on analyzing e-commerce sales data to extract meaningful business insights using Python for data analysis and SQL for querying structured data. The goal is to understand sales performance across categories, channels, and locations.

* Objective 
Analyze overall sales performance
Identify top-performing categories and regions
Compare sales across different sales channels
Understand customer and order trends
Extract actionable business insights from raw data

* Tools & Technologies Used
Python
Pandas
Matplotlib
SQL (SQLite via Python)
Google Colab
Jupyter Notebook

* Dataset Information
The dataset contains e-commerce order details including:
Order ID
Date
Status
Sales Channel
Category
Amount
City, State, Country
Fulfilment details

* Data Cleaning Steps
Removed extra spaces from column names
Standardized column naming (snake_case format)
Handled missing values
Prepared dataset for SQL querying

* Analysis Performed
1. Total Sales Analysis
Calculated overall revenue generated from all orders.

2. Category-wise Sales
Identified which product categories contribute the most revenue.

3. Sales Channel Performance
Compared performance between different sales channels.

4. Top Cities by Sales
Found regions with highest revenue contribution.

5. Sales Trend Analysis
Analyzed monthly/periodic sales trends.

* Key Insights
A few product categories contribute the majority of total revenue
Certain cities dominate in sales performance
One sales channel consistently outperforms others
Sales show variation across time periods, indicating demand fluctuations
Business performance is concentrated in specific regions

* Conclusion
This analysis helped uncover key business trends in e-commerce sales data. It demonstrates how Python and SQL can be used together to clean data, perform analysis, and generate actionable insights for decision-making.
